# Literature evidence (tracked)

Files for the WARDEN literature loop; see BOND_SEARCH.md and
`.claude/skills/warden-literature/SKILL.md`.

- `brief/` — output of `warden lit-brief` (what the calculations say, questions)
- `searches/` — raw BOND records captured with `warden bond-call`
- `proposals.json` — literature-backed candidates with verbatim quotes
- `library.json` — validated output of `warden lit-import`, for `decide --library`

Scratch databases (`*.sqlite`) are git-ignored.
